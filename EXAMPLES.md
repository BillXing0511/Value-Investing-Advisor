## 实战工作流

### 周一上午：筛选新机会
```bash
# 1. 执行筛选
python main.py schedule run-screening --limit 50

# 2. 查看结果
python main.py watchlist show --detail

# 3. 深入研究感兴趣的股票
python main.py info JPM
python main.py info JNJ

# 4. 添加分析备注
python main.py watchlist note JPM "Q3财报优秀，考虑建仓"
```

### 每日收盘后：更新数据
```bash
# 更新所有股票的最新数据
python main.py watchlist update

# 查看变化
python main.py watchlist show
```

### 周末：回顾和调整
```bash
# 1. 导出数据进行分析
python main.py watchlist export

# 2. 调整筛选标准
python main.py config edit --criterion pe_ratio --max 18

# 3. 移除不再符合标准的股票
python main.py watchlist remove XYZ
```

## 提示和技巧

1. **使用管道**: 配合其他命令行工具
   ```bash
   python main.py watchlist show | grep "Technology"
   ```

2. **批量操作**: 创建脚本批量添加股票
   ```bash
   for symbol in AAPL MSFT GOOGL; do
     python main.py watchlist add $symbol
   done
   ```

3. **定期备份**: 备份配置和数据
   ```bash
   cp config/investment_criteria.json config/backup_$(date +%Y%m%d).json
   cp data/watchlist.json data/backup_$(date +%Y%m%d).json
   ```

4. **组合使用**: 先筛选再手动筛查
   ```bash
   # 宽松筛选
   python main.py config edit --criterion pe_ratio --max 25
   python main.py screen run --limit 100

   # 手动查看并精选
   python main.py watchlist show
   ```
